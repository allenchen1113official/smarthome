OpenClaw 本地語音

OpenClaw = Whisper（語音轉文字）+ Ollama（Llama 3 推理）+ Piper（文字轉語音）+ Hermes（管家編排）。四個容器都在本機，資料不出家門。

—

一鍵串接會做什麼

  1. 在 HA 新增 Wyoming 整合 ×2（Whisper STT、Piper TTS）
  2. 在 HA 新增 Ollama 整合並指向 Hermes（Hermes 偽裝成 Ollama 端點，對話代理即 Hermes）
  3. 建立 Assist 語音助理管線「OpenClaw」（zh-TW / Whisper / Hermes / Piper）並設為預設

之後：HA → 設定 → 語音助理 檢查；Ollama 整合的「控制 Home Assistant」請設為「不控制」（由 Hermes 覆誦確認後執行）。HomePod 進聲路徑（Siri 捷徑 webhook）見 SOP 04 章。
