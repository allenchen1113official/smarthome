範例腳本：Allen 回家了

OpenClaw 接收語音 → Llama 3 推理 intent → Hermes Agent 編排 → 觸發 HA 服務
# 1) STT 結果
transcript: "Allen 回家了"

# 2) Llama 3 推理 (Ollama)
prompt: |
  使用者: {transcript}
  情境: { time: 17:23, weather: 28°C }
  輸出 JSON: { intent, person, actions[] }

response:
  intent: home_arrival
  person: Allen
  actions:
    - hue.activate_scene: "Welcome"
    - climate.set_temperature: 24
    - cover.open_cover: living_curtain

# 3) Hermes Agent 任務編排
hermes:
  parse: response.actions
  validate: { device_online: true, hours: 17 }
  dispatch:
    - service: scene.turn_on
    - service: climate.set_temperature
    - reply.tts: "Allen 回家了，冷氣已設為 24 度"

# 4) HA REST 呼叫
POST /api/services/scene/turn_on
Authorization: Bearer {LLAT}

# 5) Piper TTS
say: "Allen 回家了，冷氣已設為 24 度"
