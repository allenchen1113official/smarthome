照設計文件實作時發現三處需要修正，SOP 內已採修正後的做法並標示 ⚠️：

0.2 五條憲章原則怎麼落到 SOP

憲章 SOP 中的具體做法
I 本地優先 HAOS 自架；語音 STT/LLM/TTS 全在 Mac mini；空調加本地 IR 備援；唯一外連是行情/天氣 API（白名單）
II 可靠與優雅降級 每個情境都有「手動覆寫」與「設備離線時的行為」欄；備援機接手流程可演練
III 隱私 所有 token 進 secrets.yaml；語音不上雲；外部 API 只用匿名端點
IV 兩人可用 每個情境都有儀表板一鍵開關（input_boolean.sXX_enabled），Ann 的班別一鍵切換
V 先寫文件再部署 每個情境對應 specs/0XX 或本 SOP 第 06 章條目；部署後把 as-built 寫回

2.3 用 UTM 建立 HAOS 虛擬機（約 20 分鐘）

  1. 開 UTM → Create a New Virtual Machine → Virtualize（不是 Emulate）→ Other。
  2. Boot：勾 Skip ISO boot。
  3. Hardware：記憶體 2048 MB（設計記憶體預算 2 GB；若 Ollama 之後改小模型可提到 3072），CPU 2 核。
  4. Storage：隨便給 1 GB（等下會刪掉換成 qcow2）。
  5. Shared Directory：跳過。
  6. Summary：名稱 HAOS，勾 Open VM Settings → Save。
  7. 在 VM Settings： - System：確認 Architecture ARM64 (aarch64)，Machine QEMU 7.x ARM Virtual Machine (virt)。 - QEMU：勾 UEFI Boot（預設已勾）。 - Drives：選取剛才那顆 1 GB 磁碟 → Delete。再 New… → Import → 選 ~/VM/haos_generic-aarch64-16.2.qcow2，Interface VirtIO。 - Network：Network Mode Bridged (Advanced)，Bridged Interface 選有線 en0。MAC Address 按 Random 產生一次後記下來（DHCP 保留用）。 - Sharing：USB Sharing 只有改用 USB Stick 備案時才需要。 - Save。
  8. 按 ▶ 啟動。畫面跑完 HAOS 開機後會停在 homeassistant login: 或 ha > 提示字元。
  9. 在 VM 主控台輸入 ha network info（若是 login: 先打 root 無密碼）→ 記下 VM 拿到的 IP（動態池 .1xx）。
  10. 回路由器 DHCP 保留：把這個 MAC 保留成 192.168.0.11，然後在 VM 主控台 ha host reboot。重開後 ha network info 應顯示 192.168.0.11。

11.9 設定調整提醒

  • Companion App、Siri 捷徑 webhook、LINE webhook 反向代理、Hermes ha.urls 第一項、Wyoming 整合：全部指 VIP。
  • 不要把 LB 的 8123 綁在實體 IP，只綁 VIP（設定檔已如此），避免與節點本機的 HA 埠衝突。
  • keepalived 若要「主節點回來不搶回 VIP」加 nopreempt；本範例採搶回（priority 高者持有），因為 Mac mini 側的服務較完整。
