編排、失敗與回滾

「Allen 回家了」：s2 空調逾時 → 重試 2 次 → 反向補償 s1 → 人話回報
plan pln_2f7a  START intent=home_arrival
guard s1  device_online ok · sleep false
confirm → "要開歡迎燈並把冷氣設 24 度嗎？" ← "好"
snap  s1  hue.living = { bri:0, off }
exec  s1  light.activate_scene        OK 172ms
exec  s2  climate.set                 TIMEOUT
retry s2  1/2 (+400ms) · 2/2 (+1200ms) TIMEOUT
ABORT s2  reason=device_unreachable
compensate s1 → light.restore_snapshot OK
tts  "客廳冷氣沒回應，已把燈光還原。
      要我改開主臥冷氣嗎？"
plan ROLLED_BACK  total 6.8s
