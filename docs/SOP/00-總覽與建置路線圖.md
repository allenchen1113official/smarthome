## 0.1 這個家要長成什麼樣子

## 0.2 五條憲章原則怎麼落到 SOP

| 憲章 | SOP 中的具體做法 |
|---|---|
| I 本地優先 | HAOS 自架；語音 STT/LLM/TTS 全在 Mac mini；空調加本地 IR 備援；唯一外連是行情/天氣 API（白名單） |
| II 可靠與優雅降級 | 每個情境都有「手動覆寫」與「設備離線時的行為」欄；備援機接手流程可演練 |
| III 隱私 | 所有 token 進 `secrets.yaml`；語音不上雲；外部 API 只用匿名端點 |
| IV 兩人可用 | 每個情境都有儀表板一鍵開關（`input_boolean.sXX_enabled`），Ann 的班別一鍵切換 |
| V 先寫文件再部署 | 每個情境對應 `specs/0XX` 或本 SOP 第 06 章條目；部署後把 as-built 寫回 |

## 0.6 建置路線圖（建議 6 週）

| 週 | 目標 | 對應章節 | 完成判準 |
|---|---|---|---|
| 1 | 網路 + HAOS 開機 + 手機 App 連上 | 01、02 | 手機在 4G 下能開 `https://AllenandAnn.duckdns.org` |
| 2 | 所有設備出現在 HA、命名完成、Helpers 建好 | 03 | 儀表板能手動控制每一盞燈、每台冷氣、兩個窗簾 |
| 3 | 情境 01–12（晨間 / 下班） | 06 | 每個情境的「測試步驟」全部打勾 |
| 4 | 情境 13–28（睡眠 / 家電 / 安全） | 06 | 同上；備份排程 23 先跑起來 |
| 5 | OpenClaw + Hermes + 情境 29–35 | 04、05、06 | 說「開客廳燈」→ 覆誦 → 「好」→ 燈亮，< 2 秒 |
| 6 | 熱備演練 + 全系統驗收 | 07、08 | 關閉主節點 HAOS VM，副節點在 ~11 分鐘內自動接手並推播；回切 ≤ 10 分鐘 |

## 0.7 新手必懂的 8 個 Home Assistant 名詞

| 名詞 | 白話解釋 |
|---|---|
| HAOS | 整包作業系統版本的 Home Assistant，含 Supervisor 可裝「附加元件」 |
| 整合（Integration） | 讓 HA 認得某品牌設備的外掛，例如 Philips Hue 整合 |
| 實體（Entity） | HA 裡能看能控的最小單位，例如一盞燈 `light.living_1` |
| 區域（Area） | 房間；很多情境用區域而不是逐一列燈 |
| 輔助實體（Helper） | 自己建的虛擬開關 / 下拉 / 數字，用來記狀態（例如睡眠模式） |
| 自動化（Automation） | 觸發（trigger）→ 條件（condition）→ 動作（action） |
| 腳本（Script） | 一串可被重複呼叫的動作 |
| Package | 把某個功能的 helpers + automations + scripts 放在同一個 YAML 檔，本 SOP 每個情境一個 package |
