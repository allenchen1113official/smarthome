# 12 · 儀表板建置（壁掛平板 / 手機）

> 目標：把 Claude Design 的優化設計做成 Home Assistant 原生儀表板（Sections 版面 + 內建卡片，不需 HACS），壁掛平板與手機共用同一份；Ann 不用學就會用。
> 設計稿：`design/` 的 Claude Design 畫布（首頁 / 客廳房間頁 / 手機首頁）。

## 12.1 設計原則 → 卡片對應

| 設計重點 | HA 做法 |
|---|---|
| 首頁先回答「家現在怎樣」 | 第一個 section：兩人狀態、天氣、待處理件數（`tile` + `conditional`） |
| 「最愛」改成情境列 | `tile` 綁 `input_boolean.sleep_mode / movie_mode / guest_mode`，離家綁 `script.home_leave`（tap = 執行） |
| 房間卡片顯示實際狀態 | 每房間一個 section：`heading` 顯示溫度徽章、`tile` 燈群（亮度 feature）、`tile` 冷氣（目標溫度 feature）、`tile` 窗簾（位置 feature） |
| 修復／更新收進「系統」 | 最後一個 section，`conditional` 只在有更新或離線時出現 |
| Hermes 狀態與情境啟停 | `tile` 綁 `binary_sensor.hermes_online`；「情境總控」獨立一個 view |
| 股票圖卡 | `picture` 卡 `/local/hermes/latest.png` |

## 12.2 前置

- 03 章命名規則全部到位（`light.living_all`、`climate.living`、`cover.living_curtain`…）。
- `script.home_leave`：在 `packages/s00_common.yaml` 加一個腳本呼叫情境 04 的動作（或直接 `automation.trigger` `automation.s04_leave_home` 並 `skip_condition: true`）。
- 人員頭像：設定 → 人員 → 上傳相片（tile 會顯示）。
- 天氣 `weather.home`、空品 `sensor.aqi_home`（選配）。

```yaml
  home_leave:
    alias: 離家（手動）

    sequence:
      - action: automation.trigger

        data: { skip_condition: true }
```

## 12.4 壁掛平板設定

| 項目 | 做法 |
|---|---|
| 瀏覽器 | iPad：HA Companion App → 設定 → Companion App → 全螢幕；Android：Fully Kiosk Browser（可整合 HA 螢幕喚醒） |
| 自動喚醒 | 情境 05 / 14 的走廊動作 → `notify.mobile_app_<平板>` 命令 `command_screen_on`（Android Companion）或 Fully Kiosk REST |
| 夜間 | 23:00–07:00 主題切換深色：`frontend.set_theme` 動作 + 自動化（HA 內建深色主題） |
| 使用者 | 平板用獨立帳號 `tablet`（非管理員），儀表板「僅管理員可編輯」 |
| 儀表板預設 | 平板帳號登入後 → 儀表板 ⋮ → 設為此裝置預設 |

## 12.5 手機

同一份儀表板；Sections 在手機自動單欄。Companion App → 設定 → 捷徑：把「情境」section 的四個 tile 加成 iOS 小工具／Android Quick Settings。

## 12.6 驗收

| # | 檢查 | 通過 |
|---|---|---|
| 1 | 首頁第一屏（平板）看得到：兩人狀態、天氣、四個情境、客廳與主臥燈／冷氣／窗簾 | ☐ |
| 2 | 任何 tile 點一下 ≤ 1 秒有反應 | ☐ |
| 3 | Hermes 離線時「Hermes 離線」紅色 tile 出現；恢復後消失 | ☐ |
| 4 | 客廳房間頁逐盞燈可控、thermostat 可切模式 | ☐ |
| 5 | 情境總控能關閉任一情境並在 06 章測試中生效 | ☐ |
| 6 | Ann 不看說明 2 分鐘內切換班別與開睡眠模式 | ☐ |
